Part 5 · Now one on paper

The method for any region question, in this order.

  1. And: draw every boundary lightly in dotted lines first: the whole circle, the whole line, both whole rays. Or: sketch each region straight away, solid for ≤ or ≥ and dashed for < or >, because anything in either region counts. An Arg ray starts at the origin, and the origin itself is left out (open dot).
  2. For each condition, test a point (like 0 or 1) to see which side passes.
  3. And: shade only where every test passes. Or: shade everywhere at least one test passes.
  4. And: go over only the edges of your shaded region, solid for ≤ or ≥ and dashed for < or >. The rest of each curve stays dotted. Then check each corner: a filled dot only if the corner passes every condition (both edges solid), an open dot otherwise.

Why dotted first for “and”? A solid line says “every point on this line is in the answer”. With and, a point on the circle only counts if it also passes the other condition. Start with solid lines and you have already claimed the whole circle passes both, which is usually false. Dotted first, then check which parts satisfy both conditions, and only go over those. With or there is nothing to rule out, so you can sketch in full straight away.
